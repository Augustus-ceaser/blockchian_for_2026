# 路演录屏与截图镜头清单

## 推荐录屏顺序

1. 四角色入口和 `/roadshow`。
2. 数据产品与模型产品 published。
3. Application 兼容性矩阵。
4. 三方申请审核。
5. 合约策略来源矩阵与 4/4 确认。
6. readiness 3/3 与 Eligibility Snapshot。
7. Dispatcher、Coordinator、固定 Executor、Callback。
8. Job/Run succeeded。
9. Artifact quarantined。
10. 三方结果审核 3/3。
11. Package 精确三文件。
12. Grant 第一次下载成功。
13. Token 二次使用拒绝。
14. Audit chain valid 和边界声明。

## 必备截图

- `/roadshow` 12 节点总览。
- 数据产品和模型产品短摘要。
- 兼容性矩阵。
- 合约策略收敛矩阵。
- 执行资格矩阵。
- 真实执行时间线。
- Artifact `quarantined` 与 Package `available` 对比。
- 三方审核 3/3。
- 三文件清单。
- Grant `exhausted`、1/1。
- `result.download.completed`。
- `result.download.rejected`。
- Audit chain valid、invalid sequence 为空。

## 画面要求

- 主录制使用 1366×768 或 1920×1080。
- 保留顶部 `hard_isolation=false`。
- 不录制 Token、MinIO 管理页、数据库凭据、日志路径或原始资产。
- 移动端截图仅用于证明响应式，不作为主路演画面。
