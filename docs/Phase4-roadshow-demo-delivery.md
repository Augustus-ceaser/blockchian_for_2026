# Phase 4 路演交付与演示脚本

## 一键启动

前置条件：Docker Desktop 已启动；指定 PathMNIST NPZ 和固定权重仍位于已审查的 D 盘路径。

```powershell
cd "<repo-root>"
.\scripts\start_phase4_demo.ps1
```

打开：`http://127.0.0.1:5173/demo-login`

停止：

```powershell
.\scripts\stop_phase4_demo.ps1
```

恢复到干净演示状态：

```powershell
.\scripts\reset_phase4_demo.ps1
```

重置脚本只重建专用数据库 `medtrust_phase4_demo` 并清理精确的演示结果 bucket，不删除原始 NPZ、PTH、项目代码或迁移历史。

## 路演讲解重点

这不是“把医院数据交给 AI 企业”。演示的核心是：目录公开元数据，申请固定数据与模型版本，合同把审核范围转为可执行规则，执行器只运行白名单模型，输出先隔离，经多方审核后只交付聚合结果。

建议在以下页面停留说明：

- 数据/模型目录：数据产品与模型产品是可授权单元，不是文件下载列表；
- 数字合约：展示固定版本、1 次执行、30 天、CPU 环境和禁止项；
- 受控执行：说明运行由合同和节点能力驱动，而非前端按钮直接运行；
- 结果审核：强调“审核通过不等于原始制品公开”；
- 审计页：说明哈希链是数据库内篡改检测线索，不是第三方法律存证。

## 演示声明

本交付是使用公开 PathMNIST 和固定官方结构权重的工程原型受控推理，不是临床验证、医疗器械性能验证、生产级隐私计算、真实医院集成或国家可信数据空间测评结果。`hard_isolation=false`。
