# Phase 5.13 能力重解释矩阵

| 能力 | 当前实现 | 尚未实现 | 新定位/决策 | Connector 关系与风险 |
|---|---|---|---|---|
| ExternalDatasetCatalog | 982 条版本化元数据候选 | 权利、质量、物化与研究适用性普遍未证明 | 中央控制面；保留，作为发现入口 | 不得声称均可用或可交易；Connector 只同步获批元数据 |
| ExternalModelCatalog | 16 条元数据候选 | 权重、本地运行与供应链验证 | 中央控制面；保留并后移执行承诺 | CONCH/UNI 仍 metadata-only |
| Governance Review | 追加式审核与决议 | 医院法务、伦理和地区依据 | 治理面；扩展为 GovernanceEvidence | Connector 校验适用性、有效期和撤销 |
| DataProduct | 不可变版本、发布生命周期 | 医院 LocalAsset 与质量画像 | 中央控制面；保留并重新解释 | 产品版本映射本地资产版本，不暴露路径 |
| ModelProduct | 固定参考模型和元数据产品 | 通用安全运行与供应链证明 | 中央控制面；保留，执行资格独立 | Connector 只接受允许的固定摘要 |
| Application | 用途、范围、多方审核 | StudyProtocol、合法依据和伦理硬门 | 治理面；扩展 | 仅作为 PolicyBundle 输入之一 |
| Contract | 多方同摘要确认、策略收敛 | CA 签名、生产法律执行与动态撤销 | 中央控制面；保留，勿称 CA 电子合同 | Connector 验证摘要与当前有效性 |
| Readiness | 资格矩阵和不可变快照 | 真实节点、质量、证书和本地审批 | 医院强制执行点；扩展 | 本地最终判断优先于中央快照 |
| ComputeJob | 受控创建和派发 | 跨主机、任意任务、安全调度 | 中央编排面；保留 | 转译为不可弱化的 ExecutionOrder |
| ComputeRun | 固定 CPU 真实运行 | 医院侧隔离与生产运行 | 医院数据面；扩展 | 中央接收回执，不接收本地敏感日志 |
| Artifact quarantine | MinIO 隔离、禁止直接释放 | 医院本地隔离区和扫描 | 医院数据面；核心保留 | 未审核 Artifact 永不出域 |
| Result Review | 三方审核 | 医院独立出域责任与专业扫描 | 医院强制执行点；扩展 | 中央审核不能替代医院审核 |
| ReleasePackage | 三文件白名单安全包 | 场景化证据、签名和医院审计头 | 证据面；演进为 EvidenceBundle | 仅接收获批输出清单 |
| DownloadGrant | 一次性下载和拒绝复用 | 企业级接收方控制和撤销传播 | 证据面；保留 | 位于中央获批结果工作区 |
| DatasetModelEvidence | 声明、静态、执行、验证层级 | 多中心与医院本地证据 | 证据面；保留并扩展站点维度 | executed/verified 必须引用医院回执 |
| MaterializationPlan | 审批前置、当前外部候选阻断 | 医院本地获取、扫描和入库 | 医院数据面；后移到本地资产流程 | 中央不得借此下载医院资产 |
| Audit chain | 中央不可变事件链 | 双侧独立账本与交叉验证 | 证据面；核心扩展 | EvidenceBundle 带医院 audit head |
| Connector | 中央表和演示状态 | 独立进程、身份、证书、拒绝权 | 医院强制执行点；重新定义 | 现有对象不能宣传为已部署医院节点 |
| Capability Manifest | 关系化能力记录 | 签名版本、兼容协商和撤销 | 中央/医院边界；扩展 | Connector 签名上报，中央不能强制提升能力 |

## 通用决策

- 保留现有表和状态机，除非未来实现证明必须迁移。
- “发布”只表示目录发现，不自动表示物化、运行、临床或交易资格。
- 高风险宣传包括“真实医院已接入”“数据绝对不出域”“全部可执行”“已完成交易”和“临床准确率”。
- 外部登记、定价和收益分配作为适配器后移，不成为内部治理事实来源。
