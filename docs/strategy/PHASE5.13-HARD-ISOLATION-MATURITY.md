# Phase 5.13 Hard Isolation 成熟度

| 等级 | 能力 | 可用表述 | 升级门槛 |
|---|---|---|---|
| L0 Metadata-only | 目录、治理、无本地资产、无执行 | 元数据候选或产品目录 | 版本、来源和治理分层 |
| L1 固定任务受控本机执行 | 当前 PathMNIST + ResNet-18、固定 Executor、非临床工程验证 | 固定任务工程执行 | 真实运行、隔离结果和审计证据 |
| L2 医院 Connector 本地执行 | 独立节点、本地存储/Executor、中央无原始数据访问、医院出域审核 | 医院控制域工程候选 | 跨主机边界、独立拒绝权、双侧审计 |
| L3 强化隔离候选 | 默认禁网、只读输入、非 root、capability drop、签名镜像、配额、输出白名单、清理、攻击测试 | 强化隔离候选，不称生产硬隔离 | 系统性负面测试和运维演练 |
| L4 独立验证的硬隔离 | 生产 IAM/MFA、密钥生命周期、多租户隔离、独立安全评估、灾备、监控和生产运维 | 仅在独立验收范围内讨论 `hard_isolation=true` | 第三方测试、修复闭环、持续复评 |

当前等级为 L1，且必须显示：

```text
hard_isolation=false
```

Phase 5.13B 只建立 L2 的身份与控制骨架，不会自动达到 L2 完整闭环。Windows Docker Desktop 演示环境不得定义为 L4。等级按具体部署和证据评定，不能由产品版本号或单一测试自我授予。
