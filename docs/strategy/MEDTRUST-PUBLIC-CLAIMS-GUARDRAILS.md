# MedTrust Space 对外表述护栏

| 禁止或慎用 | 推荐表述 |
|---|---|
| 数据已确权、原始数据所有权已确认 | 已记录权利主张、依据、适用范围和审核状态 |
| 数据已匿名、绝对不可识别 | 已完成指定去标识化处理；方法、风险和复评条件见证据 |
| 数据绝对不出域 | 当前任务配置为数据留在提供方；实际隔离等级和出域证据见记录 |
| 完全合规 | 已完成列示审核；最终适用性由责任机构和专业人员确认 |
| 国家认证可信数据空间 | 工程原型，尚未完成相关测评或认证 |
| 临床级、临床准确率 | 非临床工程验证；0.95 仅对应固定 20 样本演示 |
| 已接入真实医院、已部署医院 Connector | 已完成医院控制域架构设计；真实节点尚未部署 |
| 已完成交易 | 当前处于登记、上架、意向、签约、交付、验收或结算中的具体阶段 |
| 高质量数据集 | 针对指定用途完成列示质量维度评估 |
| RWD 证明疗效 | 在指定设计和限制下观察到关联 |
| 所有模型均可运行 | 仅列示模型达到对应目录、治理、物化或执行层级 |
| 所有目录均可使用 | 目录用于发现；使用资格需单独治理、审批和验证 |

## 使用规则

1. 对外页面必须同时显示证据范围、版本、限制和责任主体。
2. “发布”不等于可下载、可执行、临床有效或交易完成。
3. 公众号文章和案例只作线索；正式主张必须回查原始法律、政策、标准和官方事实。
4. 真实患者数据项目必须取得医院审批并经过独立法律、伦理、安全和方法学审查。
5. 禁止用技术控制代替合法基础，也禁止用合同状态代替医院出域决定。
