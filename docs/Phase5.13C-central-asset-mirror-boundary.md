# Phase 5.13C Central Asset Mirror Boundary

The central mirror is a discovery and governance projection only. It does not:

- grant the central platform access to a hospital path or storage system;
- contain original data, original filenames, patient IDs, or connection data;
- create or publish a DataProduct;
- permit an application, contract, readiness decision, or execution;
- create a materialization plan, Job, Run, Artifact, package, or grant.

Only the owning hospital participant and the platform operator may read the
mirror through the existing authenticated portal.
