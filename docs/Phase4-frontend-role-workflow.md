# Phase 4 四角色前端实施报告

## 产品形态

API 模式前端不再展示单一线性 DemoStage，而是提供四个后端绑定的组织工作台：空间运营、医院数据方、AI 模型提供方和需求企业。角色切换只改变当前演示身份；可见待办、可执行命令和返回数据仍由后端授权决定。

主要实现位置：

- `frontend/src/roadshow/RoadshowContext.tsx`：四角色身份和组织上下文；
- `frontend/src/roadshow/api.ts`：带演示身份和幂等键的查询、命令与下载；
- `frontend/src/roadshow/RoadshowShell.tsx`：企业级导航、主体信息和能力边界提示；
- `frontend/src/roadshow/RoadshowPages.tsx`：目录、流程、合同、执行、结果审核/下载和审计页面；
- `frontend/src/router/index.tsx`：API 模式新路由，同时保留既有 Mock 模式；
- `frontend/src/styles.css`：桌面路演布局。

## 页面结构

- 角色工作台：当前主体、权威状态、角色职责和下一项可执行命令；
- 数据产品目录：PathMNIST 元数据、质量、来源和禁止原始导出说明；
- 模型产品目录：固定 ResNet-18 版本、入口、运行时和模型权重禁止导出说明；
- 协作流程：29 个业务步骤的事实投影；
- 数字合约：固定数据/模型/主体/次数/期限/环境/输出和四方签署证据；
- 受控执行：原子次数预留、调度、固定 CPU 推理和隔离制品；
- 结果审核与下载：强制数据出域审核、平台合规审核、模型技术确认及安全结果包；
- 审计与基础设施：AuditEvent 时间线和至少一次投递/幂等消费说明。

## 浏览器验收

在 1440×900 桌面视口完成了真实 API 浏览器链路。验证内容包括：

- 四个角色切换后工作台、组织和待办同步改变；
- 错误角色无法看到或执行不属于自己的命令；
- 执行页显示 Run 1/1 和运行完成；
- 结果页显示 Artifact 仍在隔离审核中，同时只向需求企业显示获批结果包下载；
- 下载后页面提示“一次受控下载，授权令牌已消耗”；
- 审计页显示从目录发布到 `result.download.completed` 的连续事件；
- 页面持续展示 `hard_isolation=false`、非临床、非生产隐私计算和未通过国家测评的边界。

前端类型检查和生产构建均通过。Vite 8.1.5 构建 3693 个模块成功；构建仅有常规大 chunk 提示，不影响本次路演验收。结果页在 1440×900 视口的页面宽度与滚动宽度一致，没有水平溢出。
