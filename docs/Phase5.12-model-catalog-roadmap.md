# Phase 5.12 Model Catalog Roadmap

- Phase 5.12.1: versioned public model candidate website catalog, complete.
- Phase 5.12.2: MedTrust metadata synchronization and read-only browsing,
  complete.
- Phase 5.12.3A: source, license, access, weight availability and input/output
  governance, complete. Sixteen computed profiles exist; formal reviews and
  family resolutions remain zero. No weights.
- Phase 5.12.3B1: first evidence-led batch complete. Eight candidates received
  96 append-only reviews; CONCH, UNI and Prov-GigaPath are eligible only for
  restricted metadata-only drafts. No weights or ModelProduct were created.
- Phase 5.12.3B2: complete. CONCH, UNI and Prov-GigaPath are immutable,
  metadata-only `ModelProduct` drafts bound to their governance snapshots.
- Phase 5.12.4: complete. CONCH and UNI are published for catalog discovery;
  Prov-GigaPath remains a draft. All three remain unmaterialized,
  unvalidated, unselectable and non-executable.
- Phase 5.12.5: add explicit bidirectional dataset-model evidence, separately
  distinguishing declared, schema-compatible, executed, verified,
  incompatible and execution-failed facts.
- Phase 5.12.6: consider materializing one small pinned data-model combination
  on D drive only after license, security, space and runtime approval.
- Phase 5.12.7: run one or two newly approved combinations through the existing
  Application, Contract, readiness, execution, quarantine, review, release and
  one-time download chain.

No later phase should infer compatibility from names or upstream claims.
